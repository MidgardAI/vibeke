Create and open a Git worktree

Usage: herdr worktree create [OPTIONS]

Options:
      --workspace <ID>
          

      --cwd <PATH>
          

      --branch <NAME>
          

      --base <REF>
          

      --path <PATH>
          

      --label <TEXT>
          

      --focus
          

      --no-focus
          

      --trust-repository
