# Vibeke logo

The approved logo is **Duck in a shell**, concept 14, selected on 2026-10-06.
`duck-in-a-shell.png` is the unchanged source image.

Run `bun run icons` from `web/` to export the website logo, favicons, touch icons,
link preview, PWA icons, desktop icons, and tray icons. The generator lives in
`web/scripts/brand-icons.ts`. It trims empty space, resizes the artwork, and adds
platform backgrounds. It converts light and colored details to alpha for system
notification badges and macOS tray templates.

Use the full-color transparent mark on the website. Keep its proportions. Maskable
icons use a smaller mark within the central safe area. The source is raster art;
do not describe exports as vector artwork.
