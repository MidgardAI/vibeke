Vibeke 0.1.0 is the first public release of the terminal workspace and desktop app for coding agents.

Run your usual agent CLI in a pane, manage workspaces and requests from the terminal interface, and connect from your desktop or phone.

## Install the terminal CLI

Available for **macOS on Apple silicon** and **Linux on x86_64 or ARM64**.
Install `minisign` first (`brew install minisign` on macOS, or your Linux package manager), then run:

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.1.0 sh
```

The installer verifies the release signature, checksum, and version. It installs inside your home directory without `sudo`.
Add `~/.local/bin` to your `PATH` if needed.

Start in your project:

```sh
cd your-project
vibeke
```

Complete first-run setup, then run `claude`, `codex`, or your usual agent command in a pane.
Press **Ctrl+B**, then **:** to open the command palette.

[Installation guide](https://vibeke.dev/docs/install) · [Your first workspace](https://vibeke.dev/docs/quickstart)

- **macOS:** open the DMG and drag Vibeke into Applications. ZIP archives are also available.
- **Windows:** run the EXE installer.
- **Linux:** choose the DEB for Debian-based systems or the AppImage for other distributions. A Secret Service/keyring backend is required.

The desktop app connects to a Vibeke host and does not bundle the host CLI.
For local use on a supported Mac or Linux computer, install both. Intel Macs and Windows can connect to a supported remote host.
Linux ARM64 and Windows ARM64 desktop packages are not included in this release.

[Connect the desktop app](https://vibeke.dev/docs/desktop)

## Use your phone or browser

Open [app.vibeke.dev](https://app.vibeke.dev). With a Vibeke session running on your host, pair it using:

```sh
vibeke gateway pair \
  --relay https://relay.vibeke.dev \
  --app-url https://app.vibeke.dev
```

Scan the QR code or open the printed link, then compare and confirm the device fingerprint.
The server manages the gateway after setup. You do not need to build the app or run your own relay.

[Phone and browser guide](https://vibeke.dev/docs/mobile)

## Release notes and limitations

- The CLI and desktop app are available without GitHub authentication.
- Linux host CLI binaries use static musl linking.
- The macOS desktop app is ad-hoc signed and is not notarized. The Windows installer is not publisher-signed. OS approval may be required.
- Desktop automatic updates are not configured. Download a new release to upgrade.
- Holder processes preserve running panes after a client disconnect or server restart. A host restart stops those processes.

[SHA256SUMS](https://github.com/MidgardAI/vibeke/releases/download/v0.1.0/SHA256SUMS) and its [minisign signature](https://github.com/MidgardAI/vibeke/releases/download/v0.1.0/SHA256SUMS.minisig) cover the CLI and desktop downloads.
The signed release manifest supports remote host installation. See [release verification](https://vibeke.dev/docs/releases).
