Vibeke 0.2.0 adds phone pairing and device management to the terminal interface and makes sessions recover more cleanly after a server restart.

## What's new

- **Devices view in the TUI.** Pair a phone without leaving the terminal: press `prefix+alt+d` or choose **Pair a phone** in the command palette. Choose the access level, then scan the QR code or open the link, and watch the pairing status live. The same view lists your paired devices and lets you revoke them.
- **Live phone count.** The status bar's phone count now updates as devices connect and disconnect.
- **More reliable pairing.** Pairing from the TUI tolerates late replies, reconnects and clock skew. An abandoned pairing link is cancelled.
- **Workspace names follow your work.** A workspace's automatic name follows the focused pane's directory: the Git repository name, or the directory with your home shown as `~`.
- **Quieter recovery after a server restart.** Re-adopted panes show a short "reconnected after server restart" notice instead of a permanent badge. Panes that lost output show a persistent "earlier output lost" marker. A pane counts as lost only when output it had not yet saved fell out of its buffer.
- **Hooks survive server restarts.** Agent hooks keep authenticating after a server restart, gate hooks retry briefly instead of failing, and hook commands use the installed `vibeke` path. Integration status flags hooks that point at a missing binary or a development build, and running setup again rewrites them.
- **Safer server startup.** Vibeke no longer starts a second server while one is starting, and two servers can never share a socket.

### Removed

- Pre-tool enforcement in hooks (`[agents] fail_closed`, `VIBEKE_ENFORCE`) and approval-history rule suggestions (`policy.suggest`, `[orchestrate.learned_policy]`). Hooks now report activity and gate-capable interactions only. Leftover configuration keys are reported as unknown and ignored.
- API: the `policy.suggest`, `policy.learned.list`, `policy.learned.accept` and `policy.learned.dismiss` methods and the `agent.tool_blocked`, `policy.learned_accepted` and `policy.learned_dismissed` events.

## Install the terminal CLI

Available for **macOS on Apple silicon** and **Linux on x86_64 or ARM64**.
Install `minisign` first (`brew install minisign` on macOS, or your Linux package manager), then run:

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.2.0 sh
```

The installer verifies the release signature, checksum, and version, and installs inside your home directory.
Add `~/.local/bin` to your `PATH` if needed.

Start in your project:

```sh
cd your-project
vibeke
```

Complete first-run setup, then run `claude`, `codex`, or your usual agent command in a pane.
Press **Ctrl+B**, then **:** to open the command palette.

[Installation guide](https://vibeke.dev/docs/install) · [Your first workspace](https://vibeke.dev/docs/quickstart)

## Use your phone or browser

Open [app.vibeke.dev](https://app.vibeke.dev). With a Vibeke session running on your host, open the **Devices** view (`prefix+alt+d`, or **Pair a phone** in the command palette), or run:

```sh
vibeke gateway pair
```

Scan the QR code or open the link, then compare and confirm the device fingerprint.
The server manages the gateway after setup.

[Phone and browser guide](https://vibeke.dev/docs/mobile)

## Upgrading and limitations

- Run the installer again to upgrade the CLI, then start `vibeke` again.
- Download the new desktop package to upgrade the desktop app. Desktop automatic updates are not configured.
- Linux host CLI binaries use static musl linking.
- The macOS desktop app is ad-hoc signed and is not notarized. The Windows installer is not publisher-signed. OS approval may be required.
- Holder processes preserve running panes after a client disconnect or server restart. A host restart stops those processes.

[SHA256SUMS](https://github.com/MidgardAI/vibeke/releases/download/v0.2.0/SHA256SUMS) and its [minisign signature](https://github.com/MidgardAI/vibeke/releases/download/v0.2.0/SHA256SUMS.minisig) cover the CLI and desktop downloads.
See [release verification](https://vibeke.dev/docs/releases).
