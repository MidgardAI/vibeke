Vibeke 0.6.0 names each agent after what it is working on, and shows every pane in the sidebar.

## What's new

- **Agent tabs show the session title.** A tab shows the title of the agent's session instead of only `claude` or `codex`. Vibeke reads the title from the agent's own files:
  - **Claude Code:** the name you give with `/rename`, else the title Claude Code makes for the session.
  - **Codex:** the thread name.
  - **pi:** the name you give with `/name`.
  - **omp:** the session title.
  - Until a title exists, the tab shows the first prompt.
  The browser, phone and desktop apps show the title in tabs, the sidebar and the command palette. Titles are redacted like other stored text.
- **Panes in the sidebar.** When a workspace has more than one pane, the sidebar lists each pane under it, with its status. Tap a pane to open it.
- **One tab per agent.** Each agent has one tab. The switch on the right of the tab bar shows the conversation or the terminal.

### Fixes

- The conversation no longer shows the notices that Claude Code adds when a background task finishes.
- The Changes panel says "Not a git repository" instead of showing an error code.
- On iOS 26, the Home Screen app no longer blurs the header under the status bar.

## Install the terminal CLI

Available for **macOS on Apple silicon** and **Linux on x86_64 or ARM64**.
Install `minisign` first (`brew install minisign` on macOS, or your Linux package manager), then run:

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.6.0 sh
```

The installer verifies the release signature, checksum, and version, and installs inside your home directory.
Add `~/.local/bin` to your `PATH` if needed.

Start in your project:

```sh
cd your-project
vibeke
```

Complete first-run setup, then run `claude`, `codex`, or your usual agent command in a pane.
Press **Ctrl+B** and wait to see every key, or press **Ctrl+B**, then **:** to open the command palette.

[Installation guide](https://vibeke.dev/docs/install) · [Your first workspace](https://vibeke.dev/docs/quickstart)

## Use your phone or browser

Open [app.vibeke.dev](https://app.vibeke.dev). With a Vibeke session running on your host, open the **Devices** tab of the Connections view (`prefix+alt+d`, or **Pair a phone** in the command palette), or run:

```sh
vibeke gateway pair
```

Scan the QR code or open the link, then compare and confirm the device fingerprint.
The server manages the gateway after setup.

[Phone and browser guide](https://vibeke.dev/docs/mobile) · [Sharing and handoffs](https://vibeke.dev/docs/handoff)

## Upgrading and limitations

- Run the installer again, or use **Update Vibeke…** in the command palette (`vibeke update` from a shell). Then start `vibeke`: it restarts an older server for you.
- This release changes the render protocol, so a 0.6.0 terminal cannot attach to a 0.5.0 server. Restart the server after the update. Upgrade remote machines with `vibeke machine upgrade <machine>`.
- Desktop releases update in the app where supported; otherwise download the 0.6.0 package.
- Linux host CLI binaries use static musl linking.
- The macOS desktop app is ad-hoc signed and is not notarized. The Windows installer is not publisher-signed. OS approval may be required.
- Holder processes preserve running panes after a client disconnect or server restart. A host restart stops those processes.

[SHA256SUMS](https://github.com/MidgardAI/vibeke/releases/download/v0.6.0/SHA256SUMS) and its [minisign signature](https://github.com/MidgardAI/vibeke/releases/download/v0.6.0/SHA256SUMS.minisig) cover the CLI and desktop downloads, including the desktop update feed files.
See [release verification](https://vibeke.dev/docs/releases).
