Vibeke 0.4.0 brings devices, sharing and handoffs together in one **Connections** view, and lets you share a pane or a workspace with a colleague from the terminal. It also fixes phone pairing over SSH, starting the gateway on a fresh Mac, and old servers that kept running after an upgrade.

## What's new

- **One Connections view.** Press `prefix+alt+d` to open it. Its tabs are **Devices** (your phones and apps), **People** (who you shared panes or workspaces with), **Hosts** (your other hosts and invitations) and **Handoffs** (incoming handoffs). Press `tab` or `shift+tab` to switch tabs. `prefix+shift+h` opens the Handoffs tab.
- **Share a pane or workspace from the terminal.** Press `prefix+alt+v`, or right-click a pane in the sidebar and choose **Share this pane or workspace with someone…**. Choose the pane or its workspace, the access and how long it lasts (1 hour to 7 days), and optionally the person's name. Vibeke shows a link and a QR code; they open it in the browser app. The **People** tab lists every share, and `x` removes access.
- **Three levels of access.**
  - **View**: they see the screen, the agent's conversation, the diff and the repository's files. Files that look like secrets stay hidden.
  - **View + approve**: they can also answer the agent's questions and permission requests. An approved request runs as you.
  - **Control**: they can also type into the pane and prompt its agent. This is like a shell on your machine, so Vibeke warns you and asks you to confirm first. Use it only with people you trust, and keep the time short.

  No level can share access further, remove devices, hand work off or pair hosts.
- **Answer pairing requests from any terminal.** When a phone asks to pair, press `y` to pair or `n` to reject. This now also works when your terminal is connected to the host over SSH.
- **The Devices tab hides pairing links when the gateway is offline.** It says why, and shows the QR code again when the gateway is back.
- **Copying from remote machines just works.** Text that a program on a remote host copies goes to your clipboard without asking. Set `clipboard.remote_write = "ask_once"` to be asked again. Reading your clipboard stays blocked by default.

### Fixes

- `vibeke gateway on` now finds the server when `TMPDIR` is not set, for example in a shell started with `su`.
- After an upgrade, starting `vibeke` restarts a server that still runs an older version, so the server and the gateway run the new version. `vibeke server restart` uses the installed version too. Set `VIBEKE_NO_AUTO_RESTART=1` to keep the running server.
- The text cursor in the command palette and other pickers sits after the last typed character again.

### Compatibility

- Some action names changed. `connections` opens the Connections view; `hosts` (formerly `sharing`) opens the Hosts tab. The names `phone_pairing`, `sharing_and_handoff`, `invitations` and `incoming_handoffs` are gone. Update custom key bindings that use them.
- Sharing from the terminal needs the 0.4.0 gateway on the host. Start `vibeke` once after upgrading so the server and gateway restart.

## Install the terminal CLI

Available for **macOS on Apple silicon** and **Linux on x86_64 or ARM64**.
Install `minisign` first (`brew install minisign` on macOS, or your Linux package manager), then run:

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.4.0 sh
```

The installer verifies the release signature, checksum, and version, and installs inside your home directory.
Add `~/.local/bin` to your `PATH` if needed.

Start in your project:

```sh
cd your-project
vibeke
```

Complete first-run setup, then run `claude`, `codex`, or your usual agent command in a pane.
Press **Ctrl+B**, then **:** to open the command palette.

## Use your phone or browser

Open [app.vibeke.dev](https://app.vibeke.dev). With a Vibeke session running on your host, open the **Devices** tab of the Connections view (`prefix+alt+d`, or **Pair a phone** in the command palette), or run:

```sh
vibeke gateway pair
```

Scan the QR code or open the link, then compare and confirm the device fingerprint.
The server manages the gateway after setup.

[Phone and browser guide](https://vibeke.dev/docs/mobile) · [Sharing and handoffs](https://vibeke.dev/docs/handoff)

## Upgrading and limitations

- Run the installer again, or use **Update Vibeke…** in the command palette (`vibeke update` from a shell). Then start `vibeke`: it restarts an older server for you.
- Desktop releases update in the app where supported; otherwise download the 0.4.0 package.
- Linux host CLI binaries use static musl linking.
- The macOS desktop app is ad-hoc signed and is not notarized. The Windows installer is not publisher-signed. OS approval may be required.
- Holder processes preserve running panes after a client disconnect or server restart. A host restart stops those processes.

[SHA256SUMS](https://github.com/MidgardAI/vibeke/releases/download/v0.4.0/SHA256SUMS) and its [minisign signature](https://github.com/MidgardAI/vibeke/releases/download/v0.4.0/SHA256SUMS.minisig) cover the CLI and desktop downloads, including the desktop update feed files.
See [release verification](https://vibeke.dev/docs/releases).
