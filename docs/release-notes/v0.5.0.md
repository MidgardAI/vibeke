Vibeke 0.5.0 shows every prefix key in a menu, so you no longer have to remember what comes after **Ctrl+B**.

## What's new

- **A menu after the prefix.** Press **Ctrl+B** and wait a moment. A menu rises above the status bar and lists every prefix key in groups: pane, focus, text, tab, workspace, agents, connect and session, then your own `[[keys.command]]` entries, repository commands and plugin actions. When a browser pane has focus, its keys come first.
- **It waits for you.** The menu stays open until you press a key or Escape. The 1.5 second prefix timeout only applies before the menu appears.
- **Open it at once.** Press **?** after **Ctrl+B**. This replaces the old help popup.
- **It shows your own bindings.** Items come from the active keymap, so rebinds, removed keys, ranges such as `1‥9` and plugin bindings appear as configured.
- **Key sequences.** A binding such as `prefix+m w` now works. The first key opens a submenu marked `▸`, Escape goes up one level, and the status bar reads `PREFIX m`. The default keys stay flat.
- **Resize mode shows its keys** the same way while it is active.
- **Small terminals.** When the menu does not fit beside the sidebar it uses the whole width. If rows are still cut off, the last line says how many keys are hidden and points at the command palette.
- **Settings.** Set `prefix_menu_ms` under `[keys]` to change the delay (default 400 ms, 0 shows the menu immediately), or `prefix_menu = false` to turn the menu off.

### Fixes

- The browser and desktop apps load the conversation again when the host comes back online, instead of showing "not connected" after the app resumes.

## Install the terminal CLI

Available for **macOS on Apple silicon** and **Linux on x86_64 or ARM64**.
Install `minisign` first (`brew install minisign` on macOS, or your Linux package manager), then run:

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.5.0 sh
```

The installer verifies the release signature, checksum, and version, and installs inside your home directory.
Add `~/.local/bin` to your `PATH` if needed.

Start in your project:

```sh
cd your-project
vibeke
```

Complete first-run setup, then run `claude`, `codex`, or your usual agent command in a pane.
Press **Ctrl+B** and wait to see every key, or press **Ctrl+B**, then **:** to open the command palette.

## Use your phone or browser

Open [app.vibeke.dev](https://app.vibeke.dev). With a Vibeke session running on your host, open the **Devices** tab of the Connections view (`prefix+alt+d`, or **Pair a phone** in the command palette), or run:

```sh
vibeke gateway pair
```

Scan the QR code or open the link, then compare and confirm the device fingerprint.
The server manages the gateway after setup.

[Phone and browser guide](https://vibeke.dev/docs/mobile) · [Sharing and handoffs](https://vibeke.dev/docs/handoff)

## Upgrading and limitations

- Run the installer again, or use **Update Vibeke…** in the command palette (`vibeke update` from a shell). Then start `vibeke`: it restarts an older server for you.
- Desktop releases update in the app where supported; otherwise download the 0.5.0 package.
- Linux host CLI binaries use static musl linking.
- The macOS desktop app is ad-hoc signed and is not notarized. The Windows installer is not publisher-signed. OS approval may be required.
- Holder processes preserve running panes after a client disconnect or server restart. A host restart stops those processes.

[SHA256SUMS](https://github.com/MidgardAI/vibeke/releases/download/v0.5.0/SHA256SUMS) and its [minisign signature](https://github.com/MidgardAI/vibeke/releases/download/v0.5.0/SHA256SUMS.minisig) cover the CLI and desktop downloads, including the desktop update feed files.
See [release verification](https://vibeke.dev/docs/releases).
