Vibeke 0.19.0 adds pane layout controls to the terminal interface. You can move panes between tabs, change split orientation, swap panes, and shrink or grow the focused pane.

## New in this release

### Arrange panes without restarting them

Press **Ctrl+B**, then one of these keys:

| Key | Action |
| --- | --- |
| `!` | Move the focused pane into its own tab. |
| `m` | Choose another tab in this workspace and where to place the pane. |
| `Alt+t` | Switch the nearest split between side by side and top and bottom. |
| `{` or `}` | Swap with the previous or next pane. |
| Space | Cycle equal columns, equal rows, a main pane on the left, a main pane on top, and a grid. |

Pane processes and scrollback stay in place. These actions are also in the prefix menu and command palette. Scripts can use the new `pane.toggle_split`, `pane.swap`, and `pane.arrange` API methods.

### Shrink and grow the focused pane

Resize mode now shrinks and grows the focused pane. Press **Ctrl+B**, then **r** to enter it. Left or `h` shrinks the width. Right or `l` grows it. Up or `k` shrinks the height. Down or `j` grows it. Hold Shift for a larger step. Press `=` to equalize sizes. Press Escape, Enter, or `q` to leave resize mode.

You can also press **Ctrl+B**, then **Ctrl+Arrow**. Repeat Ctrl+Arrow within 500 milliseconds without pressing the prefix again. Set `keys.resize_repeat_ms` to change this interval, or set it to `0` to disable repeats.

Resizing stops at the minimum pane size. New defaults yield to existing custom bindings. The `%` and `"` split aliases and arrow focus aliases work after the prefix while their actions keep the default bindings.

[Terminal controls](https://vibeke.dev/docs/terminal)

### Pair from an iPhone

The browser app can scan pairing QR codes on iPhone. It also helps you carry a pairing link from Safari to the app installed on your Home Screen.

### Exit an empty session

After the last pane closes, Ctrl+C can exit the TUI. A configured Ctrl+C binding still takes priority.

### TLS security update

This release updates rustls to 0.23.46 to address four security advisories.

## Install the terminal CLI

Available for **macOS 13 or later on Apple silicon or Intel** and **Linux on x86_64 or ARM64**.
Install `minisign` first (`brew install minisign` on macOS, or your Linux package manager), then run:

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.19.0 sh
```

The installer verifies the release signature, checksum, and version, and installs inside your home directory.
Add `~/.local/bin` to your `PATH` if needed.

Start in your project:

```sh
cd your-project
vibeke
```

Complete first-run setup, then run `claude`, `codex`, or your usual agent command in a pane.
Press **Ctrl+B** and wait to see every key, or press **Ctrl+B**, then **:** to open the command palette.

[Installation guide](https://vibeke.dev/docs/install) · [Your first workspace](https://vibeke.dev/docs/quickstart)

## Use your phone or browser

Open [app.vibeke.dev](https://app.vibeke.dev). With a Vibeke session running on your host, open the **Devices** tab of the Connections view (`prefix+alt+d`, or **Pair a phone** in the command palette), or run:

```sh
vibeke gateway pair
```

Scan the QR code or open the link, then compare and confirm the device fingerprint.
The server manages the gateway after setup.

[Phone and browser guide](https://vibeke.dev/docs/mobile) · [Sharing and handoffs](https://vibeke.dev/docs/handoff)

## Upgrading and limitations

- Update with `vibeke update`, or with **Update Vibeke…** in the command palette. From 0.14.1 or older, run the installer once instead (see the 0.14.2 notes).
- Update the host before using the new resize and layout controls. Older hosts show an update hint.
- 0.19.0 keeps the render protocol unchanged. The JSON API gains methods and optional fields. Existing `pane.resize` callers keep their edge-based behavior unless they select `mode: "size"`.
- Running pane processes survive a server restart. Restart the TUI client to load its new keys and menus.
- Browser shortcuts can take priority over terminal shortcuts.
- Desktop releases update in the app where supported; otherwise download the 0.19.0 package.
- Linux host CLI binaries use static musl linking.
- The macOS app is signed with an Apple Developer ID and notarized by Apple. The Windows installer is not publisher-signed, so Windows can ask you to approve it.
- Holder processes preserve running panes after a client disconnect or server restart. A host restart stops those processes.

[SHA256SUMS](https://github.com/vibeke-ai/vibeke/releases/download/v0.19.0/SHA256SUMS) and its [minisign signature](https://github.com/vibeke-ai/vibeke/releases/download/v0.19.0/SHA256SUMS.minisig) cover the CLI and desktop downloads, including the desktop update feed files.
See [release verification](https://vibeke.dev/docs/releases).
