Vibeke 0.7.0 makes the phone and browser app much more capable, and adds a Previews window to the terminal.

## What's new

### Phone and browser app

- **Start agents where you want.** **New agent** can start an agent in a new folder or in a new Git worktree with its own branch. **Again** repeats your last start. A retry never starts a second agent.
- **While you were away.** When you come back, the inbox shows a card for each workspace that changed: finished turns, files changed and the last message. With the host assistant set up, **Summarize** writes a short summary.
- **Suggested replies.** For an idle agent, the app can suggest a few short replies. A reply fills the composer. Nothing is sent until you send it.
- **Search all agents.** The command palette can search the output and conversations of every agent on every host.
- **Watch an agent's browser.** The preview tab can show an agent's browser live. With full access, you can take over, tap, type and navigate, then give control back.
- **A keys board you can arrange.** Choose a preset (Default, Claude Code or Vim), or edit the keys and add your own key sequences. Share a layout as a code. Arrow keys repeat while you hold them. Left-hand mode moves the controls to the left.
- **Better reading.** Find text in the conversation. Tap links and file paths in the output to open them. Preview Markdown, images, SVG and JSON files. See images inline in the conversation. Zen mode shows only the agent.
- **Drafts and voice.** Drafts stay per pane, also after a reload. The microphone takes the Send button's place while the box is empty, and shows your words while you speak.
- **Share into an agent.** On Android and in the installed app, share text, links or files from another app into an agent.
- **Notifications.** No notification when the app already shows the item. On browsers that allow it, a notification goes away when you answer elsewhere. An optional alert says when an idle agent's prompt cache is about to expire. A chip on each row counts down to that moment.
- **Small things.** Long-press a row to pin, rename or close it. The list does not move under your finger. Back goes up one level. Pull a sheet down to close it. Starting offline shows the last saved state. A new version waits until you tap **Update**.
- **Sandbox requests.** When a sandboxed agent asks to push a branch or copy a file out, the app shows a clear card with **Allow once** and **Deny**.

### Terminal

- **Previews window.** Press `prefix+shift+o` to see every preview, with actions. A selected preview row in the sidebar shows action chips.
- **Browser install.** `vibeke browser install` installs the full Chrome for Testing where the machine can show windows, so preview windows work too. Browser panes use that browser.
- **Labels follow the session title.** The sidebar and tab bar use the agent's session title when you have not named it.
- **Folders follow `cd`.** A pane's folder and the workspace name update after a plain `cd`, also without shell integration. New tabs open in the focused pane's folder.
- **Remote folder pickers.** On a remote machine, folder pickers list that machine's folders.

## Install the terminal CLI

Available for **macOS on Apple silicon** and **Linux on x86_64 or ARM64**.
Install `minisign` first (`brew install minisign` on macOS, or your Linux package manager), then run:

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.7.0 sh
```

The installer verifies the release signature, checksum, and version, and installs inside your home directory.
Add `~/.local/bin` to your `PATH` if needed.

Start in your project:

```sh
cd your-project
vibeke
```

Complete first-run setup, then run `claude`, `codex`, or your usual agent command in a pane.
Press **Ctrl+B** and wait to see every key, or press **Ctrl+B**, then **:** to open the command palette.

## Use your phone or browser

Open [app.vibeke.dev](https://app.vibeke.dev). With a Vibeke session running on your host, open the **Devices** tab of the Connections view (`prefix+alt+d`, or **Pair a phone** in the command palette), or run:

```sh
vibeke gateway pair
```

Scan the QR code or open the link, then compare and confirm the device fingerprint.
The server manages the gateway after setup.
Suggested replies and summaries need the host assistant. Set it up and allow it on the host first.

[Phone and browser guide](https://vibeke.dev/docs/mobile) · [Sharing and handoffs](https://vibeke.dev/docs/handoff)

## Upgrading and limitations

- Run the installer again, or use **Update Vibeke…** in the command palette (`vibeke update` from a shell). Then start `vibeke`: it restarts an older server for you.
- The render protocol is the same as in 0.6.0. Upgrade remote machines with `vibeke machine upgrade <machine>` to use the new app features with them.
- The new app features need a 0.7.0 host. With an older host, the app hides them.
- Desktop releases update in the app where supported; otherwise download the 0.7.0 package.
- Linux host CLI binaries use static musl linking.
- The macOS desktop app is ad-hoc signed and is not notarized. The Windows installer is not publisher-signed. OS approval may be required.
- Holder processes preserve running panes after a client disconnect or server restart. A host restart stops those processes.

[SHA256SUMS](https://github.com/MidgardAI/vibeke/releases/download/v0.7.0/SHA256SUMS) and its [minisign signature](https://github.com/MidgardAI/vibeke/releases/download/v0.7.0/SHA256SUMS.minisig) cover the CLI and desktop downloads, including the desktop update feed files.
See [release verification](https://vibeke.dev/docs/releases).
