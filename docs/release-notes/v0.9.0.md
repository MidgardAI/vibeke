Vibeke 0.9.0 keeps the conversation view working when one agent starts another agent. It also improves the desktop app. On your phone, new terminals now open in the right folder.

## What's new

### Conversations stay visible

An agent can start a second agent in its own pane. For example, Claude Code can run `codex exec` to review its work. In 0.7.1, Vibeke then thought that the pane had a new agent. The conversation view of the first agent showed "No transcript for this agent". The terminal still showed the conversation.

- **The pane keeps its agent.** Vibeke now sees that the second agent runs inside the first one. The first agent keeps its conversation, its status and its history.
- **Conversations come back.** Vibeke finds the conversation file of an agent from any of its actions, not only when the agent starts. This also helps when Vibeke starts while an agent is already running.
- **Claims still apply.** A claim protects files that another agent works on. When you enforce claims, an agent that another agent started still cannot edit claimed files.

### Desktop app

- **Menu-bar icon.** The macOS menu-bar icon now uses the Vibeke logo. It shows a badge when an agent needs you.
- **Every agent in one list.** The menu-bar window lists every agent on every connected host, with its status. You can move through the list with the keyboard.
- **Works offline.** The app keeps an encrypted copy of the last dashboard of each host. It also keeps the last screen of each pane. When a host is offline, the app still shows them after a restart.
- **Fixed features.** The assistant, search and the live browser view now work in the desktop app. Before, the app blocked some of the requests that these features make.

### Phone and browser

- **New terminals open in the right folder.** A new terminal now starts in the folder of the pane on your screen. The terminal interface already worked this way. Before, the new terminal started in the folder where you created the workspace. This was often your home folder.

## Install the terminal CLI

Available for **macOS on Apple silicon** and **Linux on x86_64 or ARM64**.
Install `minisign` first (`brew install minisign` on macOS, or your Linux package manager), then run:

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.9.0 sh
```

The installer verifies the release signature, checksum, and version, and installs inside your home directory.
Add `~/.local/bin` to your `PATH` if needed.

Start in your project:

```sh
cd your-project
vibeke
```

Complete first-run setup, then run `claude`, `codex`, or your usual agent command in a pane.
Press **Ctrl+B** and wait to see every key, or press **Ctrl+B**, then **:** to open the command palette.

## Use your phone or browser

Open [app.vibeke.dev](https://app.vibeke.dev). With a Vibeke session running on your host, open the **Devices** tab of the Connections view (`prefix+alt+d`, or **Pair a phone** in the command palette), or run:

```sh
vibeke gateway pair
```

Scan the QR code or open the link, then compare and confirm the device fingerprint.
The server manages the gateway after setup.
Suggested replies and summaries need the host assistant. Set it up and allow it on the host first.

[Phone and browser guide](https://vibeke.dev/docs/mobile) · [Sharing and handoffs](https://vibeke.dev/docs/handoff)

## Upgrading and limitations

- Run the installer again, or use **Update Vibeke…** in the command palette (`vibeke update` from a shell). Then start `vibeke`: it restarts an older server for you. The restart closes old collision warnings.
- The render protocol is the same as in 0.7.0. The phone and browser app is unchanged.
- Desktop releases update in the app where supported; otherwise download the 0.9.0 package.
- Linux host CLI binaries use static musl linking.
- The macOS desktop app is ad-hoc signed and is not notarized. The Windows installer is not publisher-signed. OS approval may be required.
- Holder processes preserve running panes after a client disconnect or server restart. A host restart stops those processes.

[SHA256SUMS](https://github.com/MidgardAI/vibeke/releases/download/v0.9.0/SHA256SUMS) and its [minisign signature](https://github.com/MidgardAI/vibeke/releases/download/v0.9.0/SHA256SUMS.minisig) cover the CLI and desktop downloads, including the desktop update feed files.
See [release verification](https://vibeke.dev/docs/releases).
