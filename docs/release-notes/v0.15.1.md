Vibeke 0.15.1 delivers @mentions to agents while they work, and adds security and dependency fixes.

## What's new

### Mentions reach busy agents

In 0.15.0, an agent got a message only when it was idle and its input box was empty. Now a busy agent gets the message at the next chance. The integration adds the message to your next prompt. Most integrations also add it after a tool call, or when the turn ends. Vibeke never types into the prompt while you write in it.

| Agent | When a busy agent gets the message |
| --- | --- |
| Claude Code, Codex | With your next prompt, after a tool call, or when the turn ends |
| pi, omp | With your next prompt, after a tool call, or in a new turn when the turn ends |
| OpenCode | With your next prompt, after a tool call, or in a new turn when the session is idle |
| Hermes | With your next prompt |
| ACP agents | With your next prompt, or in a new turn when the turn ends |

Other agents still get messages when they are idle. Integrations that cannot answer a hook use the new `message.take` API method to collect their queued messages.

[Mentions guide](https://vibeke.dev/docs/mentions)

### Security and maintenance

- Vibeke refuses an account server that uses plain `http://`, except on this computer. Before, a misconfigured server could receive sign-in tokens without encryption.
- The browser and phone apps decode pairing links faster. Before, a long crafted link could slow them down.
- Rust, web, Electron and CI dependencies are updated.

## Install the terminal CLI

Available for **macOS on Apple silicon or Intel** and **Linux on x86_64 or ARM64**.
Install `minisign` first (`brew install minisign` on macOS, or your Linux package manager), then run:

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.15.1 sh
```

The installer verifies the release signature, checksum, and version, and installs inside your home directory.
Add `~/.local/bin` to your `PATH` if needed.

Start in your project:

```sh
cd your-project
vibeke
```

Complete first-run setup, then run `claude`, `codex`, or your usual agent command in a pane.
Press **Ctrl+B** and wait to see every key, or press **Ctrl+B**, then **:** to open the command palette.

[Installation guide](https://vibeke.dev/docs/install) · [Your first workspace](https://vibeke.dev/docs/quickstart)

## Use your phone or browser

Open [app.vibeke.dev](https://app.vibeke.dev). With a Vibeke session running on your host, open the **Devices** tab of the Connections view (`prefix+alt+d`, or **Pair a phone** in the command palette), or run:

```sh
vibeke gateway pair
```

Scan the QR code or open the link, then compare and confirm the device fingerprint.
The server manages the gateway after setup.
Suggested replies and summaries need the host assistant. Set it up and allow it on the host first.

[Phone and browser guide](https://vibeke.dev/docs/mobile) · [Sharing and handoffs](https://vibeke.dev/docs/handoff)

## Upgrading and limitations

- Update with `vibeke update`, or with **Update Vibeke…** in the command palette. From 0.14.1 or older, run the installer once instead (see the 0.14.2 notes).
- After the update, Vibeke refreshes the integrations it manages. Restart running agent sessions so they load the new hooks and plugins.
- 0.15.1 can talk to 0.15.0. You do not have to update every machine at once. The render protocol and the API stay compatible.
- An account server must use `https://`. Plain `http://` works only for this computer (`localhost`, `127.0.0.1` or `[::1]`).
- A cloud sandbox gets the Linux `vibeke` of the same version as your host. Vibeke downloads it and checks its signature. Your host must be able to reach GitHub releases.
- Desktop releases update in the app where supported; otherwise download the 0.15.1 package.
- Linux host CLI binaries use static musl linking.
- The macOS app is signed with an Apple Developer ID and notarized by Apple. The Windows installer is not publisher-signed, so Windows can ask you to approve it.
- Holder processes preserve running panes after a client disconnect or server restart. A host restart stops those processes.

[SHA256SUMS](https://github.com/vibeke-ai/vibeke/releases/download/v0.15.1/SHA256SUMS) and its [minisign signature](https://github.com/vibeke-ai/vibeke/releases/download/v0.15.1/SHA256SUMS.minisig) cover the CLI and desktop downloads, including the desktop update feed files.
See [release verification](https://vibeke.dev/docs/releases).
