Vibeke 0.14.1 shows SSH login steps, answers questions with several parts, and shows long titles in full.

## What's new

### SSH login steps

`vibeke ssh` now shows the login steps of SSH before it connects. Before, it waited with no output.

- You see host key questions, password and two-factor prompts, and login links such as the Tailscale SSH check.
- Without a terminal, Vibeke does not wait for a prompt. It stops after a short time and tells you to run `ssh` once to log in.

### Questions with several parts

Claude Code can ask several questions in one dialog. Vibeke now handles these dialogs better.

- The inbox shows each question once. Before, the same question could appear twice.
- You can answer every question from the inbox or the card. Press a number to choose an answer. Press **Tab** or the arrow keys to move between questions. Vibeke sends the answers when every question has one.
- Vibeke checks the dialog on the screen before and after each key. It stops if the dialog is not the one you answered.
- Questions with several choices per question, and typed answers, still need an answer in the pane. The inbox tells you when this is the case.

### Titles

- The goto menu (`prefix+g`) shows the same pane titles as the sidebar and the tab bar.
- The sidebar shortens long names to fit its width, and it keeps the agent state visible.
- When you hold the mouse over a shortened row, a box shows the full title over several lines.
- The tab bar shortens all titles evenly before it hides tabs.

## Install the terminal CLI

Available for **macOS on Apple silicon** and **Linux on x86_64 or ARM64**.
Install `minisign` first (`brew install minisign` on macOS, or your Linux package manager), then run:

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.14.1 sh
```

The installer verifies the release signature, checksum, and version, and installs inside your home directory.
Add `~/.local/bin` to your `PATH` if needed.

Start in your project:

```sh
cd your-project
vibeke
```

Complete first-run setup, then run `claude`, `codex`, or your usual agent command in a pane.
Press **Ctrl+B** and wait to see every key, or press **Ctrl+B**, then **:** to open the command palette.

## Use your phone or browser

Open [app.vibeke.dev](https://app.vibeke.dev). With a Vibeke session running on your host, open the **Devices** tab of the Connections view (`prefix+alt+d`, or **Pair a phone** in the command palette), or run:

```sh
vibeke gateway pair
```

Scan the QR code or open the link, then compare and confirm the device fingerprint.
The server manages the gateway after setup.
Suggested replies and summaries need the host assistant. Set it up and allow it on the host first.

[Phone and browser guide](https://vibeke.dev/docs/mobile) · [Sharing and handoffs](https://vibeke.dev/docs/handoff)

## Upgrading and limitations

- Run the installer again, or use **Update Vibeke…** in the command palette (`vibeke update` from a shell). Then start `vibeke`: it restarts an older server for you.
- The render protocol did not change. A 0.14.0 terminal interface can still connect to a 0.14.1 server. The desktop app, the browser app and the API stay compatible.
- A cloud sandbox gets the Linux `vibeke` of the same version as your host. Vibeke downloads it and checks its signature. Your host must be able to reach GitHub releases.
- Cloud sandboxes use the provider's network. Vibeke's network profiles for local sandboxes do not apply there.
- Desktop releases update in the app where supported; otherwise download the 0.14.1 package.
- Linux host CLI binaries use static musl linking.
- The macOS app is signed with an Apple Developer ID and notarized by Apple. The Windows installer is not publisher-signed, so Windows can ask you to approve it.
- Holder processes preserve running panes after a client disconnect or server restart. A host restart stops those processes.

[SHA256SUMS](https://github.com/MidgardAI/vibeke/releases/download/v0.14.1/SHA256SUMS) and its [minisign signature](https://github.com/MidgardAI/vibeke/releases/download/v0.14.1/SHA256SUMS.minisig) cover the CLI and desktop downloads, including the desktop update feed files.
See [release verification](https://vibeke.dev/docs/releases).
