Vibeke 0.12.0 shows the images that agents attach, and it brings dev-server previews to the desktop app and to your phone.

## What's new

### Images in the terminal interface

Agents can attach images to their pane, for example a screenshot of the page they changed. The terminal interface now shows these images.

- The sidebar has an **Images** section. It lists the newest images. An image stays new until you look at it.
- Press `prefix+alt+i` to open the newest image in the viewer. Use the arrow keys to show older or newer images. Press `x` to remove an image.
- When an agent attaches an image to the pane you are using, a small card shows it. The card does not take the keyboard. Turn it off with `popup = false` in `[ui.images]`.

Images need a terminal with the kitty graphics protocol, such as kitty or Ghostty, or iTerm2. Other terminals show a short text hint. The `o` key then opens the image with your normal image program.

[Images in the terminal interface](https://vibeke.dev/docs/previews#images-in-the-terminal-interface)

### Previews in the desktop app and on your phone

A preview is a dev server that runs in a pane, for example a web app on port 3000.

- In the desktop app and the browser app, the **Previews** button in the workspace header opens the **Previews** tab of the right panel. Press `Cmd+Shift+B` (`Ctrl+Shift+B` on Windows and Linux).
- The desktop app shows the page in the panel, next to the agent. The page runs through the host connection, so it also works for a remote host. Select **Expand** to show it in the main area.
- On your phone, the host draws the page in its own browser and sends you pictures of it. Touch the page as you would any page. Use **Keyboard** to type into it. This needs full access to the host.

[Desktop guide](https://vibeke.dev/docs/desktop) · [Phone and browser guide](https://vibeke.dev/docs/mobile)

### Dismiss inbox items

You can now dismiss an inbox item or an open question that you do not need.

- In the terminal inbox (`prefix+i`), press `x` to dismiss the selected item. Press `u` to undo.
- In the browser and desktop apps, select **Dismiss** on the card.

Vibeke also closes questions by itself when the agent clearly moved on, for example when you answered in the pane.

### Fixes

- A browser pane now fills tall and narrow panes. Before, a tall pane could show the page in a short strip at the top. A narrow pane could show an empty band. Pinned devices, such as `--device iphone-15`, use the same fix.
- The preview manager (`prefix+shift+o`) opens a browser pane next to the pane you are using. Before, it opened next to the pane that runs the dev server.
- `vibeke browser pane list` no longer opens a page at `http://list/`. A single word is not a URL, so the command now stops with a hint. Use `vibeke browser panes` to list browser panes.
- The update badge follows `version_check = false` in the `[update]` section of your configuration.
- A handoff right after you start the terminal interface no longer fails with "no peer".

## Install the terminal CLI

Available for **macOS on Apple silicon** and **Linux on x86_64 or ARM64**.
Install `minisign` first (`brew install minisign` on macOS, or your Linux package manager), then run:

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.12.0 sh
```

The installer verifies the release signature, checksum, and version, and installs inside your home directory.
Add `~/.local/bin` to your `PATH` if needed.

Start in your project:

```sh
cd your-project
vibeke
```

Complete first-run setup, then run `claude`, `codex`, or your usual agent command in a pane.
Press **Ctrl+B** and wait to see every key, or press **Ctrl+B**, then **:** to open the command palette.

[Installation guide](https://vibeke.dev/docs/install) · [Your first workspace](https://vibeke.dev/docs/quickstart)

## Use your phone or browser

Open [app.vibeke.dev](https://app.vibeke.dev). With a Vibeke session running on your host, open the **Devices** tab of the Connections view (`prefix+alt+d`, or **Pair a phone** in the command palette), or run:

```sh
vibeke gateway pair
```

Scan the QR code or open the link, then compare and confirm the device fingerprint.
The server manages the gateway after setup.
Suggested replies and summaries need the host assistant. Set it up and allow it on the host first.

[Phone and browser guide](https://vibeke.dev/docs/mobile) · [Sharing and handoffs](https://vibeke.dev/docs/handoff)

## Upgrading and limitations

- Run the installer again, or use **Update Vibeke…** in the command palette (`vibeke update` from a shell). Then start `vibeke`: it restarts an older server for you.
- The render protocol did not change. A 0.11.0 terminal interface can still connect to a 0.12.0 server.
- A cloud sandbox gets the Linux `vibeke` of the same version as your host. Vibeke downloads it and checks its signature. Your host must be able to reach GitHub releases.
- Cloud sandboxes use the provider's network. Vibeke's network profiles for local sandboxes do not apply there.
- Desktop releases update in the app where supported; otherwise download the 0.12.0 package.
- Linux host CLI binaries use static musl linking.
- The macOS app is signed with an Apple Developer ID and notarized by Apple. The Windows installer is not publisher-signed, so Windows can ask you to approve it.
- Holder processes preserve running panes after a client disconnect or server restart. A host restart stops those processes.

[SHA256SUMS](https://github.com/vibeke-ai/vibeke/releases/download/v0.12.0/SHA256SUMS) and its [minisign signature](https://github.com/vibeke-ai/vibeke/releases/download/v0.12.0/SHA256SUMS.minisig) cover the CLI and desktop downloads, including the desktop update feed files.
See [release verification](https://vibeke.dev/docs/releases).
