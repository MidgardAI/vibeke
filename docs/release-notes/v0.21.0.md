Vibeke 0.21.0 improves conversation updates and tool output.

## New in this release

### New conversations start with a fresh view

Starting a new Codex conversation with `/new` now replaces the conversation view as well as the terminal view. Previous messages, expanded steps, search state, and cached images do not carry over. A delayed response from the previous conversation cannot restore its contents.

### Background work reflects completed tasks

Completed Codex agent tasks no longer stay in the background work list after their final answer. Active follow-up tasks remain visible when an older final answer arrives late.

### Read completed work with less clutter

Completed tool steps collapse into expandable groups. Empty thinking entries disappear. Codex script tools show command previews.

Tool results show readable output. Command failures keep their error status. JSON printed by commands remains unchanged. Expand a tool row to read its input and output.

The elapsed time uses the duration reported by Codex when it is available.

## Install the terminal CLI

Available for **macOS 13 or later on Apple silicon or Intel** and **Linux on x86_64 or ARM64**.
Install `minisign` first (`brew install minisign` on macOS, or your Linux package manager), then run:

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.21.0 sh
```

The installer verifies the release signature, checksum, and version, and installs inside your home directory.
Add `~/.local/bin` to your `PATH` if needed.

Start in your project:

```sh
cd your-project
vibeke
```

Complete first-run setup, then run `claude`, `codex`, or your usual agent command in a pane.
Press **Ctrl+B** and wait to see every key, or press **Ctrl+B**, then **:** to open the command palette.

[Installation guide](https://vibeke.dev/docs/install) · [Your first workspace](https://vibeke.dev/docs/quickstart)

## Use your phone or browser

Open [app.vibeke.dev](https://app.vibeke.dev). With a Vibeke session running on your host, open the TUI **Devices** view (`prefix+alt+d`, or **Pair a phone** in the command palette), or run:

```sh
vibeke gateway pair
```

Scan the QR code or open the link, then compare and confirm the device fingerprint.
The server manages the gateway after setup.

[Phone and browser guide](https://vibeke.dev/docs/mobile) · [Sharing and handoffs](https://vibeke.dev/docs/handoff)

## Upgrading and limitations

- Update with `vibeke update`, or with **Update Vibeke…** in the command palette. From 0.14.1 or older, run the installer once instead (see the 0.14.2 notes).
- Update the host and the browser or desktop app to get all conversation fixes.
- Long answers, answers over eight lines, and some special text must be entered in the Codex pane.
- 0.21.0 keeps the render protocol and JSON API compatible with 0.20.0.
- Running pane processes survive a server restart. Restart the TUI client to load the new version.
- Browser shortcuts can take priority over terminal shortcuts.
- Desktop releases update in the app where supported; otherwise download the 0.21.0 package.
- Linux host CLI binaries use static musl linking.
- The macOS app is signed with an Apple Developer ID and notarized by Apple. The Windows installer is not publisher-signed, so Windows can ask you to approve it.
- Holder processes preserve running panes after a client disconnect or server restart. A host restart stops those processes.

[SHA256SUMS](https://github.com/vibeke-ai/vibeke/releases/download/v0.21.0/SHA256SUMS) and its [minisign signature](https://github.com/vibeke-ai/vibeke/releases/download/v0.21.0/SHA256SUMS.minisig) cover the CLI and desktop downloads, including the desktop update feed files.
See [release verification](https://vibeke.dev/docs/releases).
